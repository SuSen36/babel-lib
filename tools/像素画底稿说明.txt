用途
pixelate.py 用于把参考图片批量转成低分辨率像素画底稿，生成 Minecraft 物品贴图（16×16）的手绘起稿。纯确定性图像处理，不含任何模型推理。

处理流程
- 大于 256 像素的图先降采样：全不透明用 BOX，含透明用最近邻，避免透明色渗入
- 去背景：有透明区域直接用 alpha；否则取四边逐通道中位数当背景色，从边缘洪泛去除同色背景
- 裁主体外接框，居中补成正方形
- 按面积加权平均缩到 SIDE×SIDE，覆盖率不足 50% 的格子保持透明，颜色在 OKLab 空间只对覆盖部分求均值
- 四邻不完整的边缘格 RGB×0.55，模拟物品贴图的深色描边

运行方式
在项目根目录打开终端后执行，src 为必填的源图片文件夹，out 可选：

python tools/pixelate.py <源图片文件夹>

python tools/pixelate.py <源图片文件夹> <输出文件夹>

参数
- src：源图片文件夹，必填，只处理其中的 .png
- out：输出文件夹，默认在源文件夹旁生成 images_pixel<size>
- --size：输出边长，默认 16
- --no-outline：不压暗边缘格

示例
python tools/pixelate.py C:\path\to\images
python tools/pixelate.py C:\path\to\images C:\path\to\out --size 32

依赖
- Python 3
- Pillow
- numpy

自动安装依赖
- 脚本启动时会先检查 Pillow 与 numpy
- 缺失时自动执行 python -m pip install，优先使用清华镜像源
- 若清华源取不到包，自动回退默认 PyPI 源重试；两个源都失败才报错退出

运行结果
- 逐批处理并输出进度（每 200 张一行）
- 结束输出成功数与输出目录
- 处理失败的图片写入输出目录下的 _failed.txt，逐行记录文件名与失败原因

注意事项
- 本工具生成的是像素底稿，不是色号压缩；色号压缩请用 strip_close_colors.py（档 A 感知阈值合并）
- 颜色均值与主导色回拉都在 OKLab 空间进行，不用 sRGB 伽马空间 luma，不引入抖动
- 主体占比需落在 1%–97%，否则判为失败并记录原因
- 输出为全新的 PNG，不改动源图
- 源图若涉及第三方游戏素材，进入项目或分发前请自行确认授权

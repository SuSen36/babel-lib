用途
strip_trailing_newline脚本用于批量清理项目内文本文件末尾的多余空行，保证文件以最后一个有效字符结束。

处理范围
- 递归扫描项目根目录下所有指定后缀的文本文件
- 当前处理的文件类型：`.java`、`.json`、`.toml`、`.cfg`、`.properties`、`.mcmeta`
- 自动跳过这些目录：`build`、`run`、`run-data`、`.gradle`、`.git`

清理规则
- 只移除文件末尾连续的空行与换行符，不影响文件内部内容
- 读取时使用 `utf-8-sig`，写入时使用无 BOM 的 `utf-8`，因此文件开头如果存在 BOM 会被顺带清除
- 原地覆盖文件，内容没有变化时不重写

运行方式
在项目根目录打开终端后执行：

python tools/strip_trailing_newline.py

试运行
- 追加 `--dry-run` 参数只统计将被清理的文件，不实际写入：

python tools/strip_trailing_newline.py --dry-run

依赖
- Python 3，无第三方依赖

运行结果
- 脚本会输出扫描文件总数
- 会输出本次实际启用的工作线程数量
- 会输出是否为试运行模式
- 会逐行列出本次被清理的相对路径
- 会逐行列出读取失败而跳过的文件

注意事项
- 脚本是原地覆盖文件，请先自行确认工作区改动
- 待处理文件少于 32 个时使用单线程，避免线程开销反而拖慢处理速度；达到阈值后按 CPU 核数启用最多 8 个工作线程并行处理
- 直接双击或在交互式终端无参数运行结束时，脚本会等待按回车再退出，方便查看结果

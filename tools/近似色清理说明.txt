用途
strip_close_colors脚本用于检测并合并 babel 物品贴图中肉眼无法分辨的近似色号，合并后像素布局与视觉观感保持不变。

处理范围
- 只扫描 `src/main/resources/assets/babel/textures/item` 目录
- 递归处理该目录下所有 `.png`
- 跳过完全透明的像素（alpha 为 0），其余像素只替换 RGB，保留原有 alpha

合并规则
- 将 sRGB 颜色转换到 OKLab 色彩空间
- 色差 ΔE 取 OKLab 欧氏距离乘以 100
- 两张色号距离小于阈值 `0.45` 时视为同色，可合并
- 默认阈值仍低于人眼可辨阈值（约 1.0），只会合并单通道相差 1–2 个 RGB 单位这类难以察觉的色号
- 合并以像素数最多的色号为代表色，避免主体色块被噪点色覆盖
- 如果链式相邻导致某个色号与代表色的距离超过 0.45，则保留不合并，避免误差累积

运行方式
在项目根目录打开终端后执行：

python tools/strip_close_colors.py

试运行
- 追加 `--dry-run` 只统计将被合并的色号，不实际写入：

python tools/strip_close_colors.py --dry-run

直接双击运行等同于无参数运行，会实际合并，结束后等待按回车再退出。

依赖
- Python 3
- Pillow

自动安装依赖
- 脚本启动时会先检查是否已安装 `Pillow`
- 如果没有安装，会自动执行 `python -m pip install Pillow`
- 自动安装使用清华镜像源，避免网络超时

运行结果
- 逐行列出本次被合并的图片相对路径，以及该图色号总数、合并色号数、重映射像素数
- 最后输出扫描图片总数
- 会输出本次实际启用的工作进程数量
- 会输出是否为试运行模式、当前阈值
- 会输出实际处理的图片数量、合并色号总数、重映射像素总数
- 会逐行列出读取失败而跳过的文件

注意事项
- 脚本是原地覆盖文件，请先自行确认工作区改动
- 待处理文件少于 32 个时使用单进程，达到阈值后按 CPU 核数启用最多 8 个工作进程并行处理
- 合并后可能残留少量链式相邻色号，再次运行即可继续合并，直到输出 `Processed: 0` 表示已收敛
- 脚本只处理物品贴图，不涉及方块、GUI、实体等其他纹理

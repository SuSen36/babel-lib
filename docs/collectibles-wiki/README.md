- 全部主题文档均由 collect_wiki.ps1 从 PRTS 图鉴页再生；英文名优先复用既有文档标题对照，缺失的经 wiki.gg 站内搜索补齐。
- 英文图鉴描述由 collect_wiki.ps1 生成主题文档时从 wiki.gg 的 `{{Item description}}` 模板同步抓取（幂等，可重复运行）。

## 字段说明

- **稀有度**：低稀有度（基础售价 8 源石锭）/ 中稀有度（12）/ 高稀有度（16）；部分收藏品不在商店出售故无售价。
- **效果**：单一效果直接列出；部分主题按难度/认知塑造分支列出数值差异，以子列表呈现（如 IS3【常态化/高寒化/冻土化/极地化】、IS5【现代的/近代的/古代的/史前的】）。
- **标记**：不可交换节点、可叠加计数、一次性、遭诅古物、国王/魔王/诡谲断章系列、去伪存真出现档位、内容拓展Ⅰ/Ⅱ新增等。
- **解锁/获取条件**：图鉴解锁条件或特殊获取途径；游戏内显示为"？？？"的隐藏条件按 Wiki 原文收录。
- **图鉴描述（英）**：wiki.gg 收藏品页 `{{Item description}}` 模板中的英文官方图鉴描述，已清洗 wiki 标记；该字段仅在存在英文原文时输出。

## 工具脚本

[collect_wiki.ps1](collect_wiki.ps1) 按管线顺序执行两个阶段：

1. **主题文档**：经 PRTS API 抓取全部主题图鉴页 wikitext 并解析，再生全部主题文档，同时从 wiki.gg 抓取各条目英文名与英文图鉴描述写入条目（英文名优先复用既有文档标题对照，缺失的走站内搜索回退）；
2. **通用收藏品**：比对全部主题文档，生成 ∩-通用收藏品.md（含中英双语图鉴描述）。

目标目录默认取脚本所在目录（`$PSScriptRoot`），可用 `-dir` 参数覆盖。数据全部由脚本经 API 自取，无需预置文件；脚本产生的 JSON 中间缓存（`%TEMP%`）不入库，可随时再生。将来新增主题只需在脚本内 `$themes` 表追加一行，两阶段自动覆盖。

## 已知缺口

- 部分条目的英文名与英文图鉴描述依赖 wiki.gg 收录进度，缺失时在文档内标注「待补」；来源 wiki 更新后重跑 collect_wiki.ps1 可自动补全。
- 部分支援系列收藏品的售价数据在 PRTS 详情页暂缺，对应售价行留空。
